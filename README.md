# Long COVID Symptom Transitions in the Arizona CoVHORT

INFO 526 Project 2 (Fall 2026) by Chidera Ejike.

This project uses visualization to show how individual Long COVID symptoms
persist, resolve, and return over time in the Arizona CoVHORT, and how missing
surveys and a changing symptom checklist shape what those patterns can mean.

## Repository contents

- `Proposal.qmd`: project proposal
- `data/`: de-identified CoVHORT extract and codebook (extract pending from the study team)
- `scripts/`: numbered R scripts, run in order
- `images/`: exported figures
- `presentation/`: Quarto slides

## Reproducing

Clone the repo, open `Project-02-Ejike.Rproj`, and render `Proposal.qmd`.
Until the data extract is added, numbers that depend on it show as "[pending]".
